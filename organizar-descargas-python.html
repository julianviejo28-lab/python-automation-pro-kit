Cómo organizar la carpeta Descargas con Python

Un organizador puede separar documentos, imágenes y hojas de cálculo por tipo de archivo. Este ejemplo usa el script del kit y permite revisar el plan antes de mover nada.

1. Revisa una vista previa

Descarga el kit, abre una terminal en la carpeta extraída y ejecuta el modo de prueba sobre una carpeta. La vista previa muestra los cambios sin mover archivos:

python organize_folder.py ~/Downloads --dry-run

2. Organiza los archivos

Si el resultado es correcto, ejecuta el mismo comando sin --dry-run. El script agrupa archivos por tipo y evita sobrescribir nombres existentes.

python organize_folder.py ~/Downloads

Antes de mover archivos importantes, conserva una copia de seguridad. El organizador procesa la carpeta indicada; comprueba el nombre de la ruta antes de ejecutar.
