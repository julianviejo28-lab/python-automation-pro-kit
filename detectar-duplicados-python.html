Cómo detectar archivos duplicados con Python

El nombre no basta para saber si dos archivos son iguales. El detector del kit compara hashes SHA-256 para agrupar archivos con el mismo contenido.

Empieza con el informe

Ejecuta el comando sobre una carpeta para identificar grupos duplicados. Sin una carpeta de destino, el script solo informa los grupos:

python find_duplicates.py ~/Pictures

Revisa las rutas antes de decidir qué conservar. Si quieres que el script mueva los duplicados, especifica una carpeta destino fuera de la carpeta analizada:

python find_duplicates.py ~/Pictures --move-to ~/duplicates

Haz una copia de seguridad y comprueba el destino antes de mover archivos. Mantén siempre al menos una copia del contenido que quieras conservar.
