Crear copias de seguridad ZIP con Python

Un respaldo fechado permite recuperar archivos de una versión anterior. El script del kit crea archivos ZIP y elimina las versiones que superen el límite configurado.

Guarda una copia y conserva las siete más recientes

Indica la carpeta de origen y una carpeta de destino separada:

python backup_folder.py ~/Documents ~/Backups --keep 7

El comando conserva hasta siete archivos de respaldo en el destino. Verifica que haya espacio suficiente y prueba la restauración de un archivo para confirmar que la copia sirve.

Un respaldo no sustituye a otra copia en un dispositivo o ubicación independiente. Mantén el destino fuera de la carpeta que estás respaldando.
