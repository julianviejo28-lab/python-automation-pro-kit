Renombrar archivos en lote con Python

Para una carpeta de fotos, puedes añadir un prefijo y numeración uniforme. Usa primero la vista previa para detectar nombres inesperados.

Vista previa antes de renombrar

Con el renombrador del kit, filtra por extensión y muestra el plan sin cambiar los archivos:

python bulk_rename.py ./fotos --prefix viaje_ --number --ext .jpg --dry-run

Revisa la lista y confirma que los archivos seleccionados son los correctos. Para aplicar el cambio, vuelve a ejecutar el comando sin la opción de prueba:

python bulk_rename.py ./fotos --prefix viaje_ --number --ext .jpg

Haz una copia de seguridad antes de renombrar una carpeta importante. El prefijo y la numeración ayudan a mantener un orden constante.
