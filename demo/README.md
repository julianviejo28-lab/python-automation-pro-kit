# Free CSV Audit Preview

**English** · This read-only Python utility summarizes a CSV file: rows, columns, empty cells, exact duplicate rows, and rows with the wrong number of fields. It supports comma, semicolon, tab, and pipe separators, including UTF-8 files with a BOM. It uses only Python's standard library and never changes the input.

```bash
python csv_audit_preview.py contacts.csv
python csv_audit_preview.py contacts.csv --json
```

Requires Python 3.9+. The included tests run with `python -m unittest -v`.
